=============================================================
  COMUNAPP — QUICK START GUIDE (production mode)
=============================================================

ComunApp works with its API (FastAPI + PostgreSQL). There is no
demo mode: all data comes from the database.

-------------------------------------------------------------
1) REQUIREMENTS
-------------------------------------------------------------
  · Python 3.10 or higher      →  python.org  (check "Add to PATH")
  · Node 20 or higher          →  nodejs.org

-------------------------------------------------------------
2) START THE BACKEND (API)
-------------------------------------------------------------
  cd backend
  python3 -m venv .venv
  source .venv/bin/activate          (Windows: .venv\Scripts\activate)
  pip install -r requirements.txt
  python3 seed.py                    (seeds demo data; safe to repeat)
  python3 -m uvicorn main:app --port 8000

  API available at:  http://127.0.0.1:8000
  Documentation:     http://127.0.0.1:8000/docs
  (Without DATABASE_URL uses SQLite in backend/comunapp.db)

-------------------------------------------------------------
3) START THE FRONTEND
-------------------------------------------------------------
  (in the project root)
  npm install
  Create a .env.local file with this line:
        VITE_API_URL=http://127.0.0.1:8000
  npm run dev

  Open your browser at the URL indicated by Vite
  (usually http://localhost:5173)

-------------------------------------------------------------
4) INITIAL ACCOUNT (no demo data)
-------------------------------------------------------------
  SUPERADMIN      equipo@comunapp.cl        admin123

  The superadmin accesses the internal panel at /adminapp
  (type it directly in the URL; there are no links to it).
  From there, create real communities and their users.

  If your database comes from an old deployment with demo
  communities, clean them with:  python3 seed.py --clean-demo

-------------------------------------------------------------
5) IF SOMETHING GOES WRONG
-------------------------------------------------------------
  · "Password not recognized"  →  python3 seed.py --reset-passwords
  · "Could not connect to server"
        Check that the backend is running (step 2) and that
        VITE_API_URL points to http://127.0.0.1:8000
  · Dashboard stuck on "Loading your community…" or gives a
        database error (missing column) after deployment:
            python3 migrate.py
        (adds new missing columns; idempotent)
  · In Railway: follow docs/DEPLOYMENT.md
