================================================================
  COMUNAPP — GUÍA RÁPIDA DE INICIO
  Backend Python (FastAPI + SQLAlchemy + SQLite/PostgreSQL)
================================================================

Hay UN script por sistema operativo. Ambos hacen exactamente
lo mismo: instalan el backend, siembran datos demo y lanzan la API.

  · Windows  →  comunapp.bat   (doble click)
  · Mac/Linux→  comunapp.sh    (desde la Terminal)

----------------------------------------------------------------
  MAC (macOS)
----------------------------------------------------------------
1) Instala Python 3.10 o superior:
     brew install python
   (si no tienes Homebrew: https://brew.sh — o descarga Python
   desde https://www.python.org/downloads/)

2) Abre la Terminal y entra a la carpeta del proyecto:
     cd /ruta/del/proyecto
   Truco: escribe "cd " y arrastra la carpeta a la Terminal.

3) Da permisos de ejecución y lanza el script:
     chmod +x comunapp.sh
     ./comunapp.sh

4) En el menú, presiona en este orden:
     [1]  Instalar backend completo   (solo la primera vez)
     [3]  Sembrar datos de demostración
     [2]  Iniciar API

5) Abre en tu navegador:
     http://127.0.0.1:8000/docs   ← Swagger (probar la API)
     http://127.0.0.1:8000        ← estado
   Detener la API: Ctrl + C

Alternativa manual (sin el script):
     python3 -m venv backend/.venv
     source backend/.venv/bin/activate
     pip install -r backend/requirements.txt
     cd backend
     python seed.py
     python -m uvicorn main:app --port 8000

----------------------------------------------------------------
  WINDOWS
----------------------------------------------------------------
1) Instala Python 3.10+ marcando "Add Python to PATH".
2) Doble click en comunapp.bat
3) Opciones en orden: [1] instalar → [3] sembrar → [2] iniciar.
4) Swagger: http://127.0.0.1:8000/docs
